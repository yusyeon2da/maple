# 가을 맞이 단풍 메시지 달기

## GitHub Pages 배포
1. 저장소 루트에 `index.html`과 `assets/` 폴더를 함께 업로드합니다.
2. Settings → Pages에서 `Deploy from a branch`, `main`, `/(root)`를 선택합니다.
3. 배포가 끝나면 Pages 주소로 접속합니다.

## 동작
- 작성하기 → 편지 작성 화면
- 메시지(최대 300자), 행복기숙사명, 인스타그램 아이디 필수 입력
- 개인정보 수집·이용 동의 및 편지 소개 동의 필수
- 제출 후 본인 메시지만 완료 화면에 표시
- 다른 참여자의 메시지는 표시하지 않음

## 중요
이 프로토타입은 브라우저 안에서만 메시지를 표시하며 운영자에게 정보를 전송하지 않습니다. 실제 이벤트 운영 전에는 보안이 확보된 저장 기능, 개인정보 처리 고지 및 보관·파기 절차를 별도로 준비해야 합니다.
